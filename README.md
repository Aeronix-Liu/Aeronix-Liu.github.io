# LIU Xinran · Personal Homepage

Static personal site for academic & research outreach.

## Local preview

Open `index.html` in a browser, or serve the folder:

```bash
npx --yes serve .
```

## Deploy (GitHub Pages)

1. Create a public repository named `Aeronix-Liu.github.io`
2. Push this folder to the `main` branch
3. In **Settings → Pages**, set source to **Deploy from a branch** → `main` / `/ (root)`
4. Site URL: https://aeronix-liu.github.io/
